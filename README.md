# SentinelOps

SentinelOps is a greenfield engineering-harness pilot: a secure, offline-first field operations, asset, incident, evidence, maintenance, and recovery platform.

This repository exists to test whether the Project Second Brain engineering cognition mesh materially improves software planning, architecture, security, failure analysis, implementation, verification, deployment, and operational readiness.

The primary build handoff is in `HANDOFF_SENTINELOPS_HARNESS_PILOT.md`.

Do not treat this as a generic CRUD demo. The pilot must produce working software and evidence showing how engineering decisions were routed through the cognition harness.
